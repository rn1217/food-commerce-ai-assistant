# 2026-10-02 — DB 상품 기반 AI 추천 이유

> 같은 날 후속 작업으로 자연어 조건 해석·가격 검색을 추가했다. 아래 초기 연동 기록에 이어 마지막 절에 후속 결과를 기록한다.

## 구현

상품 조회 뒤 최대 3개 후보를 Gemini에 전달하고 추천 이유만 추가했다. Pydantic으로 JSON 구조·길이를 검증하고 ID 집합 일치와 중복 여부를 검사한다. FAQ는 기존 원문 검색으로 유지한다. 새 패키지와 테이블은 추가하지 않았다.

## 문제와 개선

외부 AI 서비스가 503을 반환하면 AI 설명을 받을 수 없다. 이를 전체 검색 실패로 전파하지 않도록 LLM 호출 경계에서 오류를 잡고, DB 상품 목록을 유지하는 fallback 처리를 구현했다. 오류를 숨기지 않고 안전한 코드와 요청 ID를 기록한다.

실제 첫 통합 요청에서 HTTP 503을 받아 설명 생성에 실패했지만 서비스 응답은 HTTP 200, 상품 ID [1, 5]였다. ai_logs의 engine=gemini, status=fallback, error_code=http_503을 확인하고 저장 응답과 HTTP 응답이 같은지 대조했다. 서버 처리 시간은 4,218ms였다.

이후 브라우저 요청에서는 같은 두 상품에 실제 AI 이유가 표시됐다. 요청 ID 14d54f2b-9eba-4a10-a538-357a57e9c822의 로그는 success였다. 서버 처리 5,757ms, LLM 처리 5,713ms, API 보고 입력 토큰 364, 출력 토큰 85, 전체 토큰 1,046이었다. 전체 토큰은 내부 처리 토큰 등이 포함될 수 있으므로 입력+출력 합으로 재계산하지 않는다. 각 수치는 단일 요청 관측이며 평균이나 절감 효과가 아니다.

## 검증

자동 테스트 35개 통과. 새 테스트는 미등록·중복·누락 ID, 잘못된 JSON·자료형·빈 이유·길이 초과, 호출 생략, 후보 3개 제한, API 오류와 시간 초과, 로그 기록을 확인한다. 자동 테스트는 외부 API와 DB 쓰기를 모의 처리한다.

실제 웹 화면에서 두 상품의 AI 추천 이유를 확인했다. AI 이유를 textContent로 표시하며 상품명·가격은 DB 값을 유지한다.

## 남은 한계와 다음 작업

카드의 상품 ID 검증과 별개로 이유 문장의 사실성은 완전히 검증하지 않는다. 규칙 기반 질문 이해와 ID순 후보 선택의 한계도 남아 있다. FAQ LLM 연동, 상품 데이터 확장, 고정 평가셋과 포트폴리오 정리가 다음 작업이다.

## 후속 작업 — 자연어 조건 해석·가격 검색

사용자의 '가성비 있는 상품을 추천해줘 제일 싼 상품도 포함해서' 요청이 기존 세 가지 키워드 규칙에서 인식되지 않는 문제가 있었다. AI가 이유만 작성했기 때문에 검색 전 의도 해석은 개선되지 않았던 것이 원인이다.

Gemini 조건 해석 → 엄격한 스키마 검증 → 가격 필터/SQL 정렬로 확장했다. '가성비'를 판매가격 기준으로 명시하고 최저가는 다른 필터를 만족하는 상품 안에서 비교한다. 범위를 벗어난 숫자·SQL 형태 정렬·상충 포장 조건을 거절한다. 미지원 조건이 있으면 일부 조건만 적용하지 않는다.

동일 질의의 개선 전 결과는 지원 조건 없음/상품 0개였다. 개선 후 실제 웹 요청 641954ea-a46a-4851-be1b-61f0f8fabb63에서는 [4, 2, 1, 3, 5] 순, 가격 [12000, 24000, 28000, 32000, 35000]을 확인했다. 조건 해석과 추천 이유 모두 success, 서버 처리 14,990ms였다. 조건 해석 5,416ms, 이유 생성 9,513ms로 각각 기록됐다. 이는 단일 요청 비교 사례이며 평균 정확도·속도 개선 주장이 아니다. 해석 단계를 추가해 호출량과 대기 시간은 늘었다.

'2만원 이하 상품 중 개별포장은 제외해줘'의 실제 웹 요청은 max_price=20000, exclude_individual=true와 0개 결과였다. 현재 유일한 묶음포장 상품은 32,000원이므로 정상이다. '매운 선물' 실제 해석은 unsupported=[매운맛]으로 검색을 중단했다. 실제 DB에서도 가격 정렬/상한/포장 제외를 검증했다.

일부 실제 해석 호출은 503으로 실패했다. 복합 조건을 무시해 검색하지 않고 안전하게 재질문 안내로 처리했다. '1만5천원 미만' 문장은 실제 AI 해석 성공까지 확인하지 못했으며 SQL 14,999원 상한 적용은 DB에서 검증했다.

테스트는 45개로 늘었고 전부 통과했다. 아직 의미 해석 전체의 정확도나 모든 부정문 처리를 보장하지 않는다. 카테고리 필터와 중량 기반 가성비는 미지원이다.
