# 2026-09-18 — 환경 구성과 첫 API

### 목적

사용자의 HTTP 요청이 Python 함수로 전달되고 JSON 응답으로 반환되는 과정을 이해한다.

### 완료 내용

- Python 실행 및 프로젝트 가상환경 확인
- FastAPI와 Uvicorn 설치
- `/health` API 작성 및 브라우저 응답 확인
- `/hello` API 작성, `name` 쿼리 파라미터 및 기본값 확인
- 사용자가 브라우저에서 동작을 확인했다고 보고함
- 현재 코드와 설치 패키지를 기준으로 README와 의존성 목록 작성

### 이해한 내용

- Python 딕셔너리는 키와 값의 쌍으로 데이터를 저장한다.
- FastAPI는 함수가 반환한 딕셔너리를 JSON 응답으로 변환한다.
- `/hello?name=민수`의 `name` 값은 함수 인자로 전달된다.
- `name`을 생략하면 함수에서 지정한 기본값인 `방문자`가 사용된다.

### 확인 과정에서의 이슈

`/hello`에서 예상 인사말이 보이지 않는다는 보고가 있었다.
URL, 저장 여부, 함수 기본값을 점검하도록 안내한 뒤 정상 동작을 확인했다.
실제 오류 화면이나 수정 내역이 수집되지 않아 원인은 확정하지 않는다.
이 사례를 검증된 문제 해결 성과로 주장하지 않는다.
