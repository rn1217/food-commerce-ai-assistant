# 2026-09-29 — 최소 웹 화면 완료

## 목적과 구현

API 문서에서 JSON으로 실행하던 상품·FAQ 검색을 사용자가 입력창과 버튼으로 사용할 수 있게 했다. HTML/CSS/JavaScript를 FastAPI에서 제공하며 추가 프레임워크나 패키지를 설치하지 않았다.

상품 카드에는 실제 응답의 이름·가격·당도·포장·보관 정보를 표시하고, FAQ에는 원문과 출처를 표시한다. 화면에 LLM 미연동 및 가상 정책임을 명시했다.

## 확인 결과

- 실제 로컬 서버와 MySQL로 상품 1, 5 표시 및 배송비 FAQ 표시 확인.
- 공백 입력 시 오류 안내, 관련 없는 FAQ 질문 시 0 SOURCES/근거 없음 확인.
- 요청 중 버튼 비활성화, 응답 후 재활성화 확인.
- 모바일 너비 설정 후 세로 배치 확인. DOM 측정에서 clientWidth와 scrollWidth가 모두 375px로 가로 넘침 없음.
- 기존 백엔드 자동 테스트 24개 통과. 브라우저 테스트는 수동 검증이며 자동 UI 테스트는 추가하지 않음.

## 설계 선택과 한계

동적 문자열은 textContent로 출력하고, 중복 제출을 막으며, 실패 시 입력을 유지하도록 구현했다. 통신 오류 처리와 30초 대기 제한은 구현했지만 이번 브라우저 검증에서는 서버 중단이나 타임아웃을 강제로 재현하지 않았다.

검색 품질과 성능 개선 수치는 이번 작업에서 측정하지 않았다. 상품은 여전히 5개이며 규칙 기반 조건 추출의 부정문·미지원 조건 한계가 남아 있다. LLM API 연결, 출력 검증, 상품 데이터 확장, 평가 사례와 포트폴리오 정리가 다음 작업이다.
