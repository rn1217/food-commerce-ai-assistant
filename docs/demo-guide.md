# 화면 확인 및 캡처 안내

최신 실제 화면 캡처는 아직 없습니다. 연결된 브라우저가 없어 자동 캡처를 수행하지 못했습니다. 아래는 사용자가 실행 화면을 저장할 때 사용할 순서이며, 캡처를 완료했다는 기록이 아닙니다.

## 준비

1. 현재 `.env` 설정을 반영하려면 기존 서버를 종료하고 다시 실행합니다.
2. `http://127.0.0.1:8000/`을 열고 `Ctrl+F5`로 새로고침합니다.
3. 환경변수, 터미널의 비밀정보, 개발자 도구의 요청 헤더는 캡처하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

| faq-answer.png | FAQ에서 “배송비” | 가상 정책 답변, faqs:2 원문 보기, 원문 카드 |
| faq-no-evidence.png | FAQ에서 “비트코인 가격 알려줘” | 근거 없음 안내, 꾸며낸 답변 없음 |

Windows `Win+Shift+S`로 실제 화면을 저장하고 추후 `docs/screenshots/`에 추가할 수 있습니다. 파일이 생긴 뒤 README에 상대 경로로 연결합니다. 이미지가 없는 상태에서 링크만 만들지 않습니다.

FAQ 출처 버튼을 눌러 해당 원문 카드로 이동하고 강조되는지도 확인합니다. 좁은 화면에서는 입력창과 결과 카드가 잘리지 않는지 봅니다. 실패가 나오면 성공 화면으로 꾸미지 않고 요청 ID와 로그를 확인합니다.

## 선택: 60~90초 시연

문제와 가상 데이터 소개 → 가격/포장 조건 검색 → 해석 조건과 실제 상품 확인 → FAQ 답변과 출처 클릭 → 근거 없는 질문 안내 순으로 보여줍니다. 로컬 서비스이므로 포트폴리오의 외부 데모 링크에 `localhost` 주소를 넣지 않습니다.
